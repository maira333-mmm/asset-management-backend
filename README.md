# Asset Management System - Backend

This is the backend for the Asset Management System, built with Node.js, Express, and PostgreSQL. It is fully Dockerized for easy setup.

## Tech Stack
- **Node.js & Express.js** (Backend API)
- **PostgreSQL** (Database)
- **JWT** (Authentication)
- **Swagger UI** (API Documentation)
- **Docker** (Containerization)
